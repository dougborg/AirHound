# AirHound Flipper bridge v1 (proposed frozen codec contract)

Transport: official RPC AppDataExchange bytes, one complete AHFB message per protobuf event. Max payload256, message300 bytes. No arbitrary UART commands. All multibyte integers little-endian, reject any wrong length/reserved bits/type/version. No raw JSON or string commands.

Header44: magic[0..4] AHFB; version[4]=1; type[5]; flagsu16[6]=0; request_idu32[8]; host_nonce[12..28]; app_instanceu64[28]; message_sequenceu32[36]; payload_lengthu16[40]; reservedu16[42]=0.

Host nonce16 cryptographically random nonzero; app instance nonzero random64 generated at app launch, not a firmware boot ID. Initial Hello uses instance0, seq0. FAP binds once to nonce, returns instance; every subsequent message must match both. Host messages sequence0 (requests use request IDs), device messages strictly increase from1 across all kinds, no wrap; exhaustion terminates session. Device gaps mean delivery loss; fail current capture and require explicit new run, never silently continue binary framing. Unexpected nonce/instance rejected, not reset.

Host types: 1 Hello(empty); 2 StartBeacon(empty); 3 Pause(empty); 4 Stop(empty); 5 Heartbeat(empty). Nonzero strictly increasing requestID including heartbeats; no automatic retry of mutating requests, duplicate request ID is rejected without UART side effects. Ready means command-ready, not radio-stopped. Launch and Hello open no UART. Start is accepted from Ready/Paused and performs an explicit Stop preflight with observed stop text and clean quiet framing before sending the passive beacon command; no Start before Hello. Start again while capturing is rejected. No separate Resume: explicit StartBeacon from Paused starts a new stream generation/header. Stop is terminal for this app session; no automatic RF restart after transport loss/watchdog/error.

Device types:
0x81 Hello: capabilitiesu32 (bit0 passive_beacon; bit1 pause; bit2 watchdog; no unknown bits), compiled Flipper C ABI APImajoru16, APIminoru16 (not firmware or RPC version), UARTbaudu32, watchdog_msu32=3000, app_version_len:u8 + ASCII package version (1..32), source_revision_len:u8 + ASCII git revision (0 unknown or40hex), source_modified:u8 (0 clean,1 modified,2 unknown). This is app self-report; backend obtains Flipper firmware/UID separately, AWOK firmware unknown unless separately verified.
0x82 Ack: request_type:u8, result:u8 (0 accepted,1 invalid_state,2 invalid_payload,3 stale_request,4 unavailable). HeaderrequestID echoes request. Accepted means queued/validated, NOT UART transmitted or RF stopped.
0x83 Status fixed48: state:u8 (0 Ready,1 Preflight,2 Capturing,3 Stopping,4 Paused,5 Stopped,6 Failed), cause:u8 (0 none,1 user_pause,2 user_stop,3 watchdog,4 transport_lost,5 uart_loss,6 framing,7 preflight_failed,8 queue_loss,9 cancelled), evidenceu16 (bit0 preflight_stop_text_seen,bit1 start_text_seen,bit2 stop_text_seen; text unauthenticated, flags reset each generation), generationu32, app_uptime_msu32, uart_rx_bytesu64, uart_dropped_bytesu64, uart_error_eventsu64, rpc_dropped_messagesu64, unread_ring_bytesu32. HeaderrequestID is causing request or0 autonomous. No boolean physical RF-stop certainty. Latest cumulative counters remain valid across generations and never decrease.
0x84 Raw: generationu32, app_uptime_msu32, rawUARTbytes1..248. Includes original Marauder serial frame markers/console. Device timestamp is app receive uptime, not RF capture timestamp. Preserve producer PCAP boot-relative timestamp; host receipt location explicitly association only. Generation starts1 on explicit Start and increments without wrap. It identifies a capture generation within this FAP app instance, not an AWOK hardware boot. Raw messages have header requestID0. Reset incremental PCAP state on each generation; no gap repair.

Heartbeat every1s, device watchdog3000ms refreshed only by valid bound heartbeat/control, never by generic transport traffic. UART owner has independent nonblocking loop, local watchdog stop and bounded acknowledgment drain, no filesystem/UI/RPC wait. RPC sender uses bounded queue; enqueue failure increments loss and requests local stop; status may only be delivered later. Consumer must treat loss or missing final status as incomplete/stop unknown. Session close callback requests local stop; reset, hung HAL, power loss remain unknown. No claimed all-circumstances stop guarantee.

Pause/Stop: Ack accepted first if available, then eventual Status Stopping and Paused/Stopped only after observed exact firmware text ack plus framing/quiet drain. On missing ack => Failed with stop evidence false/unknown, not clean stopped. Source release only after bounded teardown and process/app ownership guard. No unrelated app close or device reset. Launch is no-RF; no channel assignment in v1, fixed currently configured AWOK channel remains unknown unless raw frames independently report it.

Codec goldens: every header integer boundary, max payload300, truncated/excess bytes, reserved bits, wrong enum/state, unknown version, nonce/instance mismatch, sequence/request wrap, malformed length/version text. Stateful tests: Hello no RF, duplicateStart no second UART write, invalid heartbeat cannot extend watchdog, pause/stop evidence vs accepted ack, full queue still stops, gaps no decoder splice, disconnect no resume.

The shared allocation-free codec is `companions/flipper/src/bridge.rs`; host and FAP use the same implementation. Host source integration is under development and has not been accepted on physical hardware.
