# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Astro + Starlight, accepted project website recommendation; static output, local search, repository-owned content.
## Users
People evaluating AirHound, setting up desktop/embedded/external receivers, and contributing software or signature evidence. This audience follows the accepted website roadmap #190.
## Product Purpose
Read: a project reference, not a marketing site or scanner dashboard.
Help visitors understand actual capabilities, choose compatible hardware and release assets, and find setup and contribution documentation.
## Capabilities and Constraints
AirHound observes WiFi/BLE and attaches signature evidence. Desktop is CLI. Embedded and external receiver support has specific validation limits. No fabricated hardware support, runtime signature loading, identity certainty, visitor tracking or observation uploads. The public website is distinct from a detector dashboard. The site is published at airhound.tools on GitHub Pages through the authorized deployment workflow.
## Evidence on Hand
Repository README, component docs, canonical signature JSON, release-status and receiver acceptance evidence. No approved logo or marketing photographs exist.
## Product Principles
Truthful capability boundaries; canonical documentation; explicit preview releases; accessible static content.
## Brand Commitments
AirHound name and airhound.tools domain. Approved blue schematic/field-atlas direction, plain headings and arrow-free text links. Logo remains #130.
